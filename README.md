# Multicommodity Flow Optimization & Facility Location

An academic optimization project modeling multicommodity product flow from warehouses to customers using Mixed-Integer Linear Programming (MILP).

## Features
* **MILP Optimization:** Uses `amplpy` and binary decision variables for warehouse activation.
* **Synthetic Data Generation:** Generates robust test scenarios for demand and fixed operational costs.
* **Geospatial Visualization:** Renders interactive maps of supply chains, active warehouses, and customer routes using `folium`.
